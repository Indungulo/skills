# Firecube Helper Scripts

These optional helpers run in the target plugin project's Python 3.12+ environment. Installing the skill does not install their dependencies.

| Script | Purpose | Prerequisites |
| --- | --- | --- |
| [inspect_product.py](inspect_product.py) | Inspect a product, report variables per group, and write a JSON summary. | Self-contained: `uv run inspect_product.py` installs the pinned NumPy, xarray, and netCDF4 declared in the script. With another interpreter: NumPy, xarray, and a suitable NetCDF/HDF5 backend, such as netCDF4 or h5netcdf (netCDF4 or h5py also enables walking sub-groups; without either, only the root group is reported). Not read-only: writes a sidecar JSON next to the product (or at `--out`) and, for an archive, a temporary extraction directory it removes before exiting. |
| [check_plugin_contract.py](check_plugin_contract.py) | Check a plugin's source against the Firecube contract. | Python standard library; runs standalone with `uv run`. Run it with the plugin project's interpreter so an importable Firecube installation enables additional API inspection. Fails loudly if the project has zero Python source files. |
| [check_done.py](check_done.py) | Run plugin tests, linting, ingestion, and store checks; `--json` also writes every result to a file. | Firecube, NumPy, xarray, Zarr, a suitable NetCDF backend, uv, pytest, and Ruff, plus the plugin's own dependencies and input data. Runs several ingestions and `uv run` (tests, ruff); confirm with the operator before running it, and pass a scratch directory they named with `--scratch`. Writes only a fresh subdirectory it creates for itself inside `--scratch` (removed after the run unless `--keep`); it never creates or removes `--scratch` itself, and `uv` writes its own `.venv/` and `uv.lock` inside the plugin project, not under `--scratch`. On firecube 0.1.7 a `pipeline_workers>1` run and a `resume_existing=true` rerun over a fully overlapping window are both expected to leave the store equal (the state-aware skip); on firecube 0.1.5 it falls back to that version's documented limits instead, treating the `Refusing overlapping resume append` refusal and the `pipeline_workers>1` skip as expected outcomes, not failures (plugin-traps.md). `--quick` runs the split-batch and lifecycle checks on one product of the input against a one-product reference store (extension skipped); `--regridded` skips the source-equivalence figures for plugins that bin or resample onto another grid. A missing `uv`/`firecube` executable or a command timeout is reported as a one-line FAIL, not a traceback. |

Use versions compatible with the plugin project; this skill targets Firecube 0.1.7, with a documented fallback for 0.1.5. Review the selected environment's dependencies and licenses separately.

Each script provides usage and its exit codes with `--help`: 0 when every check passed, 1 when a check failed, 2 for invalid arguments. See [plugin development](../references/plugin-development.md) for the workflow and required inputs.
